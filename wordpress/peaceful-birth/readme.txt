=== The Peaceful Birth ===
Requires at least: 6.4
Tested up to: 7.2
Requires PHP: 7.4
License: GPLv2 or later

Business theme for The Peaceful Birth doula services.

== Setup ==
1. Appearance → Themes → Add New → Upload Theme → choose peaceful-birth.zip → Activate.
   A "Home" page and a "Leave a Review" page are created and Home is set as the front page.
2. Appearance → Customize → Peaceful Birth settings: WhatsApp number, email, Instagram,
   Google review link.
3. Pages → Home: edit any text, swap the illustrations for real photos (click image → Replace).
   Removed a section by mistake? Add block (+) → Patterns → Peaceful Birth.
4. Buttons can link to #whatsapp, #instagram, #review or #contact.
5. Optional: Appearance → Menus to build a custom menu (otherwise section links are shown).
